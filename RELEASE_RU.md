# Aevrix AI 3.0 — результат обновления

12 октября 2026 года. Подготовлена сборка с рабочим сервером, новым интерфейсом и миграцией. Исходный пользовательский архив и первая исправленная копия сохранены. Внешнее размещение не менялось.

## Что изменилось

1. **Отдельные диалоги.** Создание, переименование, архив, восстановление и удаление выбранного чата. Сервер проверяет владельца каждого диалога, сообщения и файла.
2. **Память и история.** Длинные реплики больше не обрезаются до 600 символов. Для аккаунта контекст строится из БД; старые обмены при заполнении token budget сворачиваются в сводку. Явные предпочтения между чатами доступны в настройках с выключателем и удалением.
3. **Управление ответом.** Stop отменяет запрос провайдера; retry/перегенерация сохраняет версии без дубля вопроса. Редактирование создаёт отдельную ветку. Незавершённый ответ имеет статус partial/cancelled/failed. Если вопрос не успел сохраниться, текст возвращается в черновик.
4. **Учебные режимы.** Объяснение, подсказка, проверка решения и мини-тест — настройки реального диалога и системного промпта.
5. **Документы.** PDF/TXT/MD сохраняются в аккаунте, разбиваются на фрагменты и участвуют в PostgreSQL full-text поиске. Ответ содержит страницу и цитату. Удаление файла удаляет производные фрагменты. Поиск лексический; OCR и embeddings не подключены.
6. **Источники и изображения.** Общий поиск выделен в Tavily/Brave, доступны режимы Авто/Включён/Выключен. Прогноз погоды и курс имеют структурированные данные и дату. Вложения защищены владельцем и восстанавливаются из БД. Генерация изображения получает и проверяет результат на сервере, ключ не оказывается в публичном URL.
7. **Интерфейс.** Сохранён зелёный «Сигнал», тёмная/светлая темы и волна. Добавлены sidebar, многострочное поле, черновики, статус этапа, управление прокруткой, версии, экспорт всего выбранного разговора, материалы и память. Голос и закладки сохранены.
8. **Безопасность и запуск.** Лимиты до обработки JSON и на API, проверка типов, CSP/Origin, закрытая admin, обязательный webhook secret, проверяемый TLS БД, транзакции, миграция и startup recovery. Репорты сохраняются надёжно и честно показывают доставку. Логи не содержат текста разговоров или IP.

SQL выполнялся на PGlite — PostgreSQL в WebAssembly, а не на SQL-моках. Внешние ИИ/поисковые API заменены только в тестах. В рабочем `npm start` нет фиктивных ответов; без ключа интерфейс сообщает об ограничении. Платных генераций в этой работе не выполнялось.

Миграция сохранила все 205 записей старого тестового формата и при повторе не создала дублей. Для реальной непустой старой БД требуется проверенный backup; `LEGACY_BACKUP_CONFIRMED=true` — подтверждение backup, а не автоматическая его проверка.

Скриншоты большого экрана, чата, светлой темы и мобильного режима находятся в `Aevrix3-checks/`. Экспорт проверен по полному JSON Blob: браузер отменял фактическое сохранение скачиваемого файла в этой sandbox. Поэтому успешное скачивание на обычном компьютере пока не подтверждено.

## Как запустить

Распаковать `AevrixAI-3.0.zip`, перейти в его папку `AevrixAI-3.0`. Нужен Node.js 22.22.2 или новее.

```powershell
npm ci --ignore-scripts
Copy-Item .env.example .env
npm start
```

Перед запуском заполнить `GROQ_API_KEY`; для аккаунтов/документов — `DATABASE_URL` и случайный `JWT_SECRET` минимум 32 байта. Пример конфигурации и подробные инструкции backup/миграции/отката находятся в `README.md` внутри проекта. Без БД доступны гостевые диалоги.

Для просмотра с заведомо тестовыми ответами и временной БД: `npm run preview`. Это отдельный локальный тестовый режим, не сервер для публикации.

## Что ещё требуется перед реальным релизом

- Проверить конкретные ключи, доступность/стоимость моделей, текстовый ответ, vision, источники, документ и изображение. Доступен `npm run check:models` для metadata-проверки; реальные ключи в работе не предоставлены.
- Проверить внешнюю PostgreSQL по TCP/TLS, backup и миграцию на копии настоящих данных. Тесты PGlite не подтверждают сертификаты/сетевое размещение облачной БД.
- Проверить экранную клавиатуру реального iPhone/Android и фактическое скачивание экспортов. Автоматические размеры браузера не заменяют эту проверку.
- Настроить HTTPS, reverse proxy и лимиты. Сборка рассчитана на **один инстанс/worker**; для нескольких нужны общий limiter и координация запросов.

Автоматическое удаление данных по умолчанию отключено. Для аккаунта действует лимит вложений 60 МБ; для документов — 5 МБ/150 страниц; для изображений — 6 МБ. Полный перечень ограничений приведён в README.

Не реализованы embeddings/OCR, папки проектов, полноценный голосовой разговор с перебиванием, публичные отзываемые ссылки, scheduler, платежи и выполнение кода. Этапы, предусмотренные заданием как основные — диалоги, надёжность, UI, учебный режим — реализованы; документы добавлены как следующий локальный этап. Готовность внешнего production-релиза пока не объявляется.
